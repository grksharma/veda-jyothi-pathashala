# veda-jyothi-pathashala
Veda Jyothi Pathashala is an online Vedic learning platform led by Sri Konduri Pavan Kumar Sharma Garu. Through authentic teaching, disciplined practice, and the timeless Guru–Shishya tradition, it helps students learn Veda adhyayanam, Sanskrit, chanting, and Sanatana Dharma values from anywhere in the world.
